## Need More Help?

Contact [support@realigned.io](mailto:support@realigned.io) and include:

- the app edition and hosting type;
- the Jira project type and the page where the problem occurs;
- the steps you took and the result you expected;
- the exact error message, if one appears;
- a screenshot with sensitive issue data removed.

Do not send passwords, API tokens, or confidential issue descriptions.
