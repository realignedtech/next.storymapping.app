---

Advanced Story Maps extends the core story-mapping workflow for teams with more complex Jira structures. Jira remains the source of truth, while each map provides a focused planning view of the issues, relationships, and fields the team already uses.

## What Advanced adds

- Create and manage multiple story maps in a Jira project.
- Build maps from configurable issue types and link relationships.
- Add an optional activity or goal level above the backbone.
- Use a Jira board as the source for a dynamic map, including its issues and quick filters.
- Create static maps for manually curated planning views.
- Plan with sprint, release, free-form, or custom-field swimlanes.
- Configure issue cards and view progress statistics.
- Export a map as a PNG image.
- Enable or disable the app for selected projects.
- Use Jira Advanced Roadmaps parent-child relationships when the Jira configuration supports them.
