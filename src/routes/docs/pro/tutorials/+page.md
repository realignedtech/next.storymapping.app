These tutorials cover advanced features and complex workflows available in Advanced Story Maps. Each tutorial provides step-by-step instructions with practical examples.

## How to follow a tutorial

Each tutorial lists the settings it changes and the Jira data it reads, then walks through the steps in order. Work in a test project if you want to try a configuration before applying it to a live map. You can undo most changes by reopening the map settings.

## Available Tutorials

### Advanced Configuration

- **[Custom Field Swimlanes](/docs/tutorials/custom-field-swimlanes)** - Set up custom field swimlanes for advanced story map organization

### Project Management

- **[Multi-Project Releases](/docs/tutorials/multi-project-releases)** - Coordinate releases across multiple Jira projects using Advanced Story Maps

## Prerequisites

These tutorials assume you have:
- Advanced Story Maps license and installation
- access to the Jira projects, boards, issues, and fields used by the tutorial
- Basic familiarity with story mapping concepts
