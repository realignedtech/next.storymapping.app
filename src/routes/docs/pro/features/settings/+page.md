# Settings

Advanced Story Maps provides comprehensive configuration options to customize your story mapping experience. From visual preferences to integration settings, these options help you tailor the app to your team's specific needs.

## Accessing Settings

### User Settings

Personal preferences that apply only to your account:

**Location**: User avatar menu → Settings
**Scope**: Individual user preferences
**Sync**: Settings sync across browser sessions

### Project Settings

Project-wide configurations that affect all team members:

**Location**: Project administration → Apps → Advanced Story Maps
**Scope**: All users in the project
**Permissions**: Requires project admin privileges

### Map Settings

Settings specific to individual story maps:

**Location**: Map toolbar → Settings (⚙️ icon)
**Scope**: Current map only
**Access**: Map viewers and editors
