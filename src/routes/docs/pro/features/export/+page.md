---
title: 'PNG Export'
description: "Export an Advanced story map as a PNG image so you can share the current plan with stakeholders or attach it to a report."
---

PNG export is available in Advanced Story Maps. It saves a visual snapshot of the map for a presentation, planning record, or page that cannot embed the live Jira view.

![Export control in Advanced Story Maps](/docs/mockups/export-menu.svg)

## Export a map

1. Open the map and arrange the view you want to capture.
2. Apply any filter or swimlane view that should appear in the image.
3. Open the **More actions** menu (the ⋯ icon in the upper-right corner).
4. Select **Export as PNG**.
5. Save the generated PNG file.

The image represents the current visual state. It is not a live view and does not update when Jira issues change. Review the image before sharing it because visible issue summaries and fields can contain internal information.

For structured Jira data or reporting, use Jira's own export and reporting tools. Advanced Story Maps does not export PDF or CSV files.
