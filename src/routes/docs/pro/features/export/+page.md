# Export Features

Advanced Story Maps provides powerful export capabilities to help you share your story maps with stakeholders, create reports, and analyze your project data. Choose from multiple export formats to suit different needs.

## Available Export Formats

### PDF Export

Create high-quality PDF documents perfect for presentations and stakeholder reviews.

**Features:**
- **High Resolution**: Vector-based graphics for crisp printing
- **Custom Layouts**: Portrait or landscape orientation
- **Branding Options**: Include your company logo and colors
- **Pagination**: Automatic page breaks for large maps
- **Annotations**: Include notes and descriptions

**Best Use Cases:**
- Executive presentations
- Project documentation
- Stakeholder reviews
- Offline reference material

### CSV Export

Export structured data for analysis in spreadsheets and other tools.

**Included Data:**
- Issue keys and summaries
- Status and priority information
- Assignee and reporter details
- Custom field values
- Epic and component relationships
- Swimlane assignments

**Best Use Cases:**
- Data analysis and reporting
- Import into other tools
- Bulk data operations
- Progress tracking

### Image Export

Generate high-resolution images of your story maps.

**Supported Formats:**
- **PNG**: Best for web sharing and presentations
- **JPEG**: Compressed format for smaller file sizes
- **SVG**: Scalable vector format for web use

**Best Use Cases:**
- Website integration
- Wiki documentation
- Email attachments
- Social media sharing

## How to Export Your Map

### Basic Export Process

1. **Open Your Map**: Navigate to the story map you want to export
2. **Access Export Menu**: Click the **Export** button (📤 icon) in the toolbar
3. **Choose Format**: Select your desired export format from the dropdown
4. **Configure Options**: Customize export settings based on your needs
5. **Generate Export**: Click **"Export"** to create your file
6. **Download**: Save the generated file to your device

### Export Options by Format

#### PDF Export Options

**Layout Settings:**
- **Orientation**: Portrait or Landscape
- **Page Size**: A4, Letter, Legal, or Custom
- **Margins**: Adjust spacing around content
- **Scale**: Fit to page or use custom scaling

**Content Options:**
- **Include Legend**: Show status colors and symbols
- **Show Issue Details**: Include summaries and descriptions
- **Custom Fields**: Select which fields to display
- **Swimlane Labels**: Include or hide swimlane headers

**Branding:**
- **Header/Footer**: Add custom text or logos
- **Color Scheme**: Use default or custom colors
- **Font Selection**: Choose from available fonts

#### CSV Export Options

**Data Selection:**
- **Issue Fields**: Choose which Jira fields to include
- **Custom Fields**: Select relevant custom fields
- **Calculated Fields**: Include estimated vs. actual time
- **Relationship Data**: Epic links, parent/child relationships

**Format Options:**
- **Delimiter**: Comma, semicolon, or tab-separated
- **Text Encoding**: UTF-8, ASCII, or other formats
- **Date Format**: Various date formatting options
- **Number Format**: Decimal separators and currency

#### Image Export Options

**Resolution Settings:**
- **DPI**: 72 (web), 150 (standard), 300 (high quality)
- **Size**: Custom width/height in pixels
- **Quality**: Compression level for JPEG format

**Visual Options:**
- **Background**: Transparent or solid color
- **Zoom Level**: Overview or detailed view
- **Cropping**: Full map or selected area

## Advanced Export Features

### Scheduled Exports

Set up automatic exports for regular reporting.

**Configuration:**
- **Frequency**: Daily, weekly, or monthly
- **Format**: Choose export format and options
- **Recipients**: Email list for automatic delivery
- **Filters**: Export only specific data

### Batch Export

Export multiple maps at once for comprehensive reporting.

**Features:**
- **Multi-map Selection**: Choose multiple maps from your project
- **Consistent Formatting**: Apply same settings to all exports
- **Bulk Download**: Receive all exports in a single ZIP file

### Custom Templates

Create reusable export templates for consistent formatting.

**Template Options:**
- **Layout Presets**: Save preferred page layouts
- **Field Selection**: Define standard field sets
- **Branding Settings**: Consistent company branding
- **Naming Conventions**: Automatic file naming

## Export Best Practices

### Choosing the Right Format

**Use PDF when:**
- Sharing with external stakeholders
- Creating formal documentation
- Presenting to executives
- Archiving project snapshots

**Use CSV when:**
- Performing data analysis
- Creating custom reports
- Integrating with other tools
- Tracking progress metrics

**Use Images when:**
- Embedding in websites or wikis
- Quick visual sharing
- Social media or blog posts
- Lightweight documentation

### Optimizing Export Quality

**For PDFs:**
- Use landscape orientation for wide maps
- Include legends for stakeholder clarity
- Test print preview before sharing
- Consider splitting large maps across pages

**For CSV:**
- Include relevant context fields
- Use consistent date formats
- Document field meanings for recipients
- Clean data before export

**For Images:**
- Use appropriate resolution for intended use
- Consider file size for sharing methods
- Include context in surrounding documentation
- Test visibility at target display sizes

### File Management

**Naming Conventions:**
- Include project name and date
- Use version numbers for iterations
- Specify export type in filename
- Follow organizational standards

**Version Control:**
- Keep export history for reference
- Document changes between versions
- Use descriptive commit messages
- Archive old versions appropriately

## Troubleshooting Exports

### Common Issues

**Export takes too long:**
- Reduce map complexity
- Lower image resolution
- Limit included fields
- Export smaller sections

**PDF formatting issues:**
- Check page orientation
- Adjust margins and scaling
- Verify font availability
- Test with different browsers

**CSV encoding problems:**
- Specify UTF-8 encoding
- Check delimiter settings
- Verify special character handling
- Test with target application

**Missing data in exports:**
- Check user permissions
- Verify field visibility
- Review filter settings
- Confirm data availability

### Performance Optimization

**Large Map Exports:**
- Split into multiple exports
- Use lower resolution images
- Limit included custom fields
- Export during off-peak hours

**Browser Compatibility:**
- Use latest browser versions
- Clear cache before exporting
- Disable browser extensions
- Check popup blocker settings
