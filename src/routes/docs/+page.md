Story Maps for Jira turns Jira issues into a visual map of the user journey. The map places the work people do across the top and the issues that deliver each step underneath. This structure helps a team discuss sequence, scope, and priority without moving its backlog out of Jira.

## Choose your edition

**Story Maps for Jira** provides one map in each Jira Software project. It uses epics as the backbone, displays the issues below them, and lets you plan with sprint or release swimlanes.

**Advanced Story Maps for Jira** adds multiple maps, flexible issue and link types, custom-field swimlanes, configurable cards, statistics, PNG export, and maps that can span projects.

Not sure which edition fits? [Compare the editions](/download).

## Jira remains the source of truth

The app reads Jira issues and writes supported planning changes back to Jira. A person's Jira permissions still determine which projects and issues they can see or edit. Use the map as a planning view, then use the issue itself when you need the full Jira record.
